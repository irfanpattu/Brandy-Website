# BRANDY Static Website (HTML, CSS, JavaScript)

No Next.js, Node.js, npm or build step is required.

## Preview in VS Code
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` → Open with Live Server.
4. Save changes to refresh the preview.

## Edit
- `index.html`: page text, sections, links.
- `styles.css`: colors, layout, responsive design, hover effects and animations.
- `script.js`: sticky blur header, mobile menu, scroll reveal, enquiry form.
- `images/`: logo and illustrations. Replace these local image files with your own images if preferred.

## Contact form
In `script.js`, add your own WhatsApp number (international digits only) or business email. The form opens a prefilled WhatsApp message or email draft; it does not save leads to a database.

## Guarantee wording
The first-month no-pay promise is shown for Social Media Management and Performance Marketing. Before launch, define eligibility, agreed deliverables, feedback/review period, cancellation timing and exclusions (such as ad spend and third-party costs). Publish only if BRANDY can honour the promise.

## Before deployment
Replace `https://your-domain.com/` in the canonical URL with your real domain. Review privacy policy, contact details, images and all content.

## Deploy to Vercel
Push this folder to GitHub, import the repository in Vercel, choose Other if asked, and leave the build command empty. Set output directory to `.` if requested. Vercel will serve the static files directly.
